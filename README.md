# AirBnB Data Cleaning with Python
![](https://github.com/temee0/AirBnB-Intensive-Data-Cleaning-with-Python/blob/main/airbnb_image.webp)

Airbnb is a major platform in the short-term rental industry, connecting hosts with travelers looking for affordable and flexible accommodation. The industry generates large amounts of data that can be used to study pricing, customer preferences, and market trends.

### About the Dataset
The dataset used in this project contains Airbnb listing data with information related to properties, pricing, location and availability. Since it was messy and unstructured, it required cleaning to fix missing values, duplicates, inconsistent formats, and other data quality issues before analysis.

## Project Overview
This project focuses on cleaning and preprocessing a messy Airbnb dataset using Python. The objective was to improve data quality and prepare the dataset for accurate analysis and visualization. Since raw datasets often contain inconsistencies, missing values, duplicate records, and incorrect formatting, this project applies a structured data cleaning process to make the data more reliable and usable.

### Tasks Performed
- Removed redundant and unnecessary columns
- Identified and deleted duplicate records
- Handled and removed missing (NaN) values
- Cleaned individual columns for consistency and accuracy
- Corrected data types where needed
- Fixed spelling inconsistencies and formatting issues
- Resolved computation and data entry errors

### Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

# Outcome
The final dataset is cleaner, more consistent, and ready for further exploratory data analysis, visualization, or machine learning tasks. This project demonstrates the importance of data cleaning as a critical step in the data analysis workflow.
